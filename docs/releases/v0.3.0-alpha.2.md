# NextX v0.3.0-alpha.2

发布日期：2026-08-09

本版本收口最新 P0/P1 审核问题，重点保证“一键安装”和“收藏到裁决到草稿”的主链在干净环境可复现。

## 重点修复

- 声明 `setuptools`/`wheel` 构建依赖并恢复 build isolation，修复 CI 与新建虚拟环境安装失败；wheel 现在携带 schemas/prompts。
- 收藏 Signal 同时兼容 `原帖` 与 `原始内容` 标题，恢复 Bookmark → Decision 主链。
- Outcome 早期窗口到期后拒绝迟到回填；Playbook 按 Decision/experiment 统计独立样本，支持零动作 `stop`。
- 冷启动阶段生成 Conversion 行动；北极星改为 `do Decision → review-ready Artifact`，Planner 完成数只统计 published/measured。
- Artifact 格式必须匹配 Decision 推荐格式；Outcome、View、账号注册表和 Agent handoff 写入统一受 Vault 锁保护。
- 修正 Skill `default_prompt` 语义校验，并将独立安装器默认 ref 固定为本发行 tag。

## 验证

- 143 项 Python 回归测试通过。
- 隔离 wheel 安装后 `nextx version`、`contracts`、`collector-prompt` 均可用。
- Skill 语义校验、源码编译和安装器回归通过。
